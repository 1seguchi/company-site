# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。
HTML・CSS・JavaScript をすべて `index.html` 1ファイルにまとめた、1ページ構成のサイトです。

> **注意**：社名・代表者名・住所・実績の数値などは、すべて架空のものです。

## 概要

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヘッダー | ロゴとナビゲーション（スマホ幅ではハンバーガーメニュー） |
| お知らせ欄 | ヘッダー直下に、最新のお知らせ3件を5秒ごとに切り替えて表示 |
| メインビジュアル | キャッチコピーと、相談・実績へのボタン |
| 事業内容 | Webアプリ／モバイルアプリ／クラウド／AI・データの4分野 |
| 私たちの強み | 実績の数字（カウントアップ表示）と強み3つ |
| 開発実績 | 物流・ヘルスケア・金融の事例3件 |
| 会社概要 | 代表メッセージと会社情報 |
| お知らせ | お知らせの一覧 |
| お問い合わせ | 入力フォーム（デモのため送信はされません） |
| フッター | サイトマップと所在地 |

### 主な特徴

- パソコン・スマホのどちらの画面幅にも対応
- OSのダークモード設定に合わせて配色を自動で切り替え
- スクロールに合わせて各セクションをアニメーション表示（OSで「視差効果を減らす」を設定している場合は停止）
- インストールやビルドは不要で、ブラウザで開くだけで表示可能

### ファイル構成

```
company-site/
├── index.html   … サイト本体（HTML・CSS・JavaScript）
└── README.md    … このファイル
```

## ブラウザで index.html を開く手順

### 方法1：ダブルクリックで開く（いちばん簡単）

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Microsoft Edge や Google Chrome など）でサイトが表示されます。

### 方法2：ブラウザを指定して開く

1. `index.html` を右クリックします。
2. 「プログラムから開く」を選び、使いたいブラウザを選択します。

### 方法3：ブラウザにドラッグ＆ドロップする

1. ブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法4：コマンドで開く（Windows）

PowerShell やコマンドプロンプトで、このフォルダに移動してから次を実行します。

```powershell
start index.html
```

## 補足

- 文字のフォント（Noto Sans JP・Inter）は Google Fonts から読み込んでいます。インターネットに接続していない場合は、PC標準のフォントで表示されます。
- お知らせ欄の中身は、ページ下部の「お知らせ」セクションの上から3件を自動で取り込んでいます。お知らせを追加するときは、そのセクションの先頭に追記してください。
- お知らせ欄やスクロール時の表示アニメーションは JavaScript で動いています。ブラウザで JavaScript を有効にしてご覧ください。
